## Diagnostic (5 lignes)

92'MBA est une bibliothèque de lecture business hors ligne : fiches originales, extraits du domaine public, texte collé ou fichier `.txt`. Le nom et la catégorie « Éducation » du brouillon App Store ne décrivent pas un cursus MBA, ni un système de révision. La passe 1, déjà sur `main`, empêche d’écraser la clé `92mba:v1` quand la lecture échoue ou que le JSON est illisible. Le risque le plus haut encore ouvert était l’enregistrement suivant : il réécrivait un objet fermé, perdait les champs inconnus, adoptait une version future, et avalait un échec d’écriture (`persist.ts` de `dd0e94be`, ancien `setItem(...).catch(() => undefined)` vers la ligne 209). Cette branche ajoute une seule fondation : quarantaine de version, conservation des parties non modifiées, erreur visible avec réessai, export brut sur action explicite, déconnexion distincte de l’effacement, et bascule future limitée à une clé isolée contrôlée par hash et compteurs.

## Domaine vérifié

Le domaine est lu dans le produit, pas déduit du seul nom.

- `README.md` : bibliothèque business hors ligne, lecteur, recherche, import `.txt`, FR/EN/AR.
- `src/lib/library.ts` : 11 documents intégrés (`licenseAudit` exige `BUILTIN_DOCS.length === 11`). Sept fiches originales (stratégie, bilan, coûts, 4P, leadership, négociation, مبادئ الإدارة), trois extraits (Taylor 1911, Smith 1776 ch. I et II), un emplacement réservé `placeholder-vos-cours` (`library.ts:205`).
- `src/lib/features.ts:9-10` : `FEATURE_AI = false`, `FEATURE_ACCOUNT = false`. Aucun compte, aucune clé, aucun `fetch` dans `src/` (contrôlé par `scripts/passe1-scan.mjs`).
- Progression = page, nombre de pages, horodatage (`stateMerge.ts`, type `Progress`). Aucun quiz, aucun score de maîtrise, aucun algorithme d’espacement dans `src/`.
- `store/ios-metadata.md` classe l’app en Éducation / Livres et dit déjà de ne pas laisser entendre un diplôme. C’est un brouillon, rien n’a été soumis.

Comparaison utile, sans chiffre d’usage inventé :

- Apple Livres conserve la position, les signets, les notes et les surlignages, et peut les synchroniser via iCloud quand le compte Apple est activé. Guide Apple : [Accéder aux livres sur d’autres appareils](https://support.apple.com/guide/iphone/access-books-on-other-apple-devices-iphb886e1752/ios). 92'MBA reste sur un seul appareil et n’a pas de compte.
- Anki est l’exemple classique de répétition espacée (planification de cartes). 92'MBA n’a pas ce mécanisme. La pédagogie de récupération, d’espacement et de validité est donc **NA**. La progression de lecture, elle, existe.
- AsyncStorage 2.x, version déclarée `2.2.0` dans `package.json`, est un stockage clé-valeur non chiffré. React Native le déconseille pour des secrets : [Security](https://reactnative.dev/docs/security). Les limites Android documentées : environ 6 Mo au total par défaut, et environ 2 Mo par entrée à cause de la fenêtre curseur SQLite : [Known limits, AsyncStorage 2.0](https://react-native-async-storage.github.io/2.0/advanced/Limits/). Ce dépôt n’a pas mesuré ces plafonds sur un appareil.

## Douze axes

### 1. Vision

Promesse tenue dans le code : lire hors ligne, reprendre la page, ajouter un texte possédé ou libre de droits. Promesse à ne pas élargir : ce n’est pas un diplôme, pas un tuteur, pas un cloud. Le document `placeholder-vos-cours` est encore un exemple intégré (`library.ts:205`, texte dans `src/data/original.ts`). Il s’affiche avec la bibliothèque intégrée. Il n’est pas écrit à la place des données de l’appareil quand un chargement échoue (test `corruptDoesNotInstallPlaceholder`).

### 2. Fonctions

Présentes : bibliothèque, filtres, lecteur paginé, thèmes, signets, recherche accent-insensible, historique, import `.txt` / collage, FR/EN/AR, RTL arabe, progression « continuer ». Absentes et assumées : compte, sync, IA, paiement, quiz. Écart de données, traité ici : notes, nom de fichier, identifiant de compte éventuel et champs futurs étaient jetés au prochain `set`, parce que `mergeStored` (`stateMerge.ts:108`) reconstruit un objet aux seules clés connues.

### 3. UX iPhone, iPad, web, RTL

`app.json` : `orientation` portrait, `ios.supportsTablet: true`, `web.output: single`, `experiments.baseUrl: /92mba`. L’interface a un `direction` RTL (`src/lib/i18n.tsx`) et le lecteur inverse les flèches pour un document arabe (`src/app/doc/[id].tsx`). Il n’y a pas de mise en page iPad spécifique (colonnes, Split View). Le web et le natif partagent AsyncStorage / `localStorage`. Aucun de ces écrans n’a été ouvert sur un appareil dans cet audit.

### 4. Accessibilité

La passe 1 teste un contraste d’au moins 4,5:1 pour les textes de lecture et les badges (`src/lib/passe1.check.ts`, fonction `checkContrast`). Le critère de référence est WCAG 2.2, succès 1.4.3 : [Understanding 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum). Le test enregistre aussi que l’or `#C9A227` sur la crème `#F7F4EE` reste sous 4,5:1 ; le texte clair doit passer par `accentInk` (`theme.ts:17-20`). Des rôles `accessibilityRole` existent sur les boutons. Le Dynamic Type iOS n’est pas branché. La PR #2 ouverte couvre déjà une passe accessibilité : ce correctif ne la refait pas.

### 5. Architecture, hors ligne, CI, tests

Une clé : `STORAGE_KEY = '92mba:v1'` (`src/lib/store.ts:9`). Le workflow `.github/workflows/pages.yml` ne part que sur `main`, lance `tsc` et `expo export`, puis déploie GitHub Pages. Il ne lance pas `npm test` (lignes 27-29). Les tests de cette branche sont `npm test` : `passe1.check.ts`, `preservation.check.ts`, `passe1-scan.mjs`. Ils tournent dans ce dépôt, en mémoire, sans appareil. `preservation.check.ts` est exclu de `tsc` (`tsconfig.json`) parce que le projet n’a pas les types Node ; `tsx` l’exécute.

### 6. Performance et batterie

Pas de réseau sur le chemin de lecture. L’écriture est différée de 150 ms (`persist.ts`, `saveDelayMs`). La recherche parcourt les documents dans le thread JS (`library.ts`, `searchDocs`). Un import long reste un seul JSON. Le garde-fou d’écriture refuse un payload d’au moins 2 000 000 octets avant `setItem` (`preservation.ts:16`, `persist.ts:260`). Ce seuil reprend le plafond documenté « around 2 MB » d’AsyncStorage Android. Il n’a pas été mesuré sur un téléphone. Un paragraphe de 250 000 caractères, lui, est réécrit et relu dans le test.

### 7. Sécurité, nLPD, RGPD

Données locales : progression, signets, historique, textes ajoutés, préférences. Pas de compte. La politique du dépôt (`public/privacy/index.html`, 27 octobre 2026) dit qu’aucune donnée n’est envoyée aux serveurs de l’éditeur et cite la nLPD et, le cas échéant, le RGPD. Cet audit n’est pas un avis juridique. La CNIL rappelle que des données seulement locales, sans transmission, ne créent pas le même régime qu’un traitement par l’éditeur, et que l’export machine et l’effacement sont les bons outils quand un responsable détient les données : [recommandation applications mobiles](https://www.cnil.fr/sites/default/files/2024-09/recommandation-applications-mobiles.pdf), [préparer l’exercice des droits](https://www.cnil.fr/fr/preparer-lexercice-des-droits-des-personnes). Le produit gagne ici un export JSON explicite et un effacement en deux pressions, distinct de la déconnexion. Le stockage reste non chiffré. L’export natif passe par la feuille de partage du système : l’écran de l’app n’affiche pas le JSON. Ce n’est pas un chiffrement, et ce n’est pas une preuve que la sauvegarde iCloud ou Android restaure tout.

### 8. Linguistique

Trois dictionnaires complets (`src/i18n/strings.ts`, type `Dict`). L’arabe d’interface est RTL. La recherche retire les diacritiques latines et arabes (`library.ts`, `normalize`). Les nouveaux messages de quarantaine, d’échec d’écriture, d’export et de déconnexion existent en FR, EN et AR. Ils ne disent pas « corrompu » et ne collent aucun texte de l’utilisateur.

### 9. Pédagogie — NA pour la récupération, l’espacement et la validité

Il y a une progression de lecture (page la plus loin, pourcentages, « terminé »). Il n’y a pas de rappel actif, pas d’intervalle, pas de critère de maîtrise, pas de banque d’items validée. Marquer ces trois dimensions **NA** est factuel. Ajouter des quiz pour « faire éducation » sortirait du domaine vérifié et n’est pas proposé comme correctif de cette semaine.

### 10. IA, coût, sûreté, vie privée

`FEATURE_AI` est faux. Le badge « service optionnel indisponible » ne s’affiche que si l’IA était allumée (`features.ts`). Aucune clé `EXPO_PUBLIC` d’API n’est appelée. Un résumé IA reste décrit comme phase 2, hors du chemin de lecture (`README.md`). Coût actuel : 0 appel. Rien à optimiser tant que le drapeau reste faux.

### 11. Stores, croissance, monétisation, éthique

Brouillon uniquement (`store/ios-metadata.md`) : gratuit, sans compte, catégorie Éducation. Risques déjà écrits dans ce brouillon : fonctionnalité minimale (guideline 4.2) et contenu de démonstration (le placeholder). Aucune soumission n’a été faite ici. Pas d’achat intégré dans le code. Éthique de contenu : la fiche Smith signale un vocabulaire daté (`library.ts` vers la note du chapitre). Les en-têtes Gutenberg sont retirés, avec un TODO explicite pour Mohamed dans les chaînes `gutenbergTodo`. La monétisation et la croissance ne justifient pas de lire les textes importés hors de l’appareil.

### 12. Synergies

Aucun pont vers une autre app, aucun profil partagé, aucun identifiant publicitaire. `logout()` retourne `no-account` et n’écrit rien (`persist.ts:356`). Un futur compte ne doit pas réutiliser `reset()` comme déconnexion : le bouton d’effacement porte la phrase `resetNotLogout`. Les champs inconnus (`accountId`, `importBatch`) restent dans la clé s’ils existent déjà ; ils ne sont pas affichés.

## Ce que le correctif fait

- Adopte un document sans `schemaVersion` (appareils déjà installés) et un document `schemaVersion: 1`.
- Copie et vérifie une version refusée sous `92mba:v1:quarantine` (suffixe daté si une copie différente existe déjà). N’écrit pas la clé d’origine. N’applique pas l’objet en mémoire.
- Au `set`, réécrit les clés modifiées et laisse le reste, y compris les types non adoptés (`"page": "12"`, `fontScale: "large"`, signets mixtes) tant que ce champ n’est pas celui qui change.
- Si `setItem` jette, ou si le JSON atteint 2 000 000 octets : avertissement neutre, disque inchangé, `retrySave()`.
- Export : deuxième pression, téléchargement web ou feuille de partage. Le state React ne stocke pas le JSON. Le rapport montre des comptes et 16 caractères hexadécimaux.
- `logout()` ne touche pas le disque. L’effacement total reste `reset()`, deux pressions, refusé si la copie de secours n’est pas relue à l’identique (comportement passe 1 conservé).
- `restoreIsolated` prépare une future bascule. Il n’est pas appelé au démarrage. Il n’écrit jamais `92mba:v1`.

## Inconnues assumées

- Aucun iPhone, iPad, Android ou navigateur n’a été lancé. Les tests sont un stockage en mémoire.
- Le plafond 2 000 000 octets est le chiffre retenu à partir de la doc AsyncStorage 2.0 (« around 2 MB »), pas une mesure sur un Pixel ou un iPhone. iOS et le quota `localStorage` du web ne sont pas mesurés. Le total Android documenté de 6 Mo n’est pas testé.
- Une sauvegarde iCloud, un transfert d’appareil ou une restauration Android ne sont pas des garanties de zéro perte. Ce correctif ne les promet pas.
- La mémoire de l’app, après un refus pour taille, garde la saisie pour pouvoir réessayer. Une seconde lecture du disque retrouve l’ancien document. Si l’app est tuée avant un réessai réussi, la saisie nouvelle n’est pas au disque.
- L’historique au-delà de 12 survit à un changement de préférence. Il ne survit pas à la prochaine réécriture de `searchHistory` (nouvelle recherche ou effacement). L’effacement d’historique reste un seul appui.
- Les champs inconnus d’un document ne sont pas montrés dans la fiche. Ils sont dans l’export brut.
- La feuille de partage native reçoit le JSON. L’écran Réglages, non.
- `tsc` ne type pas `preservation.check.ts`.
- GitHub Actions ne lance pas encore `npm test`.
- La politique HTML n’a pas été réécrite.
- Aucune validation humaine automatisée n’est déclarée. Les tests sont des assertions sur des fixtures.

## Prompts d’implémentation (les 5 suivants)

### Prompt 1 — déjà réalisé par cette PR

Conserver la clé `92mba:v1`. Ne pas adopter `schemaVersion` autre que `1` ou absent. Ne pas réécrire les champs non modifiés. Montrer `write-failed` et réessayer. ### Prompt 2 — CI sans déploiement

Ajouter un workflow GitHub qui tourne sur pull request : `npm ci`, `npx tsc --noEmit`, `npm test`. Ne pas ajouter de job `deploy-pages`. Ne pas changer `baseUrl`, le bundle id, ni `eas.json`. Critère : la PR de ce workflow montre un run vert de `preservation checks ok` dans les logs, et zéro step `deploy-pages`.

### Prompt 3 — historique

Rendre l’effacement de l’historique aussi explicite que `reset` : deux pressions, phrase distincte de la déconnexion. Décider, par un test, si une nouvelle recherche a le droit de ramener le disque de 40 entrées à 12. Si oui, le test doit l’affirmer avec ces deux nombres. Si non, la réécriture doit garder la queue non affichée et le test de 40 doit rester vert après `pushSearchHistory`. Ne pas toucher au mode Focus de la PR #2. Éviter d’éditer les mêmes blocs que cette PR dans `settings.tsx` si le conflit n’est pas nécessaire : l’historique est dans `search.tsx` et `store.ts`.

### Prompt 4 — placeholder et brouillon store, sans soumission

Remplacer ou retirer `placeholder-vos-cours` par un contenu original déjà assumé, ou le masquer hors des listes. Ajuster `store/ios-metadata.md` pour dire « bibliothèque de lecture business » et retirer toute lecture possible comme diplôme. Ne pas lancer EAS, ne pas ouvrir App Store Connect, ne pas modifier le bundle id. Critère : `licenseAudit()` reste à 0 problème, `BUILTIN_DOCS` ne contient plus un `statusCode: 'placeholder'`, et `git diff` ne touche pas `eas.json`.

### Prompt 5 — long document

Un document dont un paragraphe fait 250 000 caractères doit rester au disque (test déjà vert) et ne pas figer le premier rendu. Introduire un plafond d’affichage mesuré (par exemple paginer au plus N caractères par frame, N écrit dans le test) sans abaisser le plafond de conservation de 2 000 000 octets et sans couper le fichier dans `92mba:v1`. Tester N avec un fixture, pas sur appareil. Si le thread dépasse le plafond d’affichage, montrer un message neutre et garder l’export complet.
